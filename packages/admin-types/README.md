# @osdlc/ontogen-admin-types

The `AdminFieldDef` and `AdminEntityConfig` types that the `admin-registry.ts` generated by [ontogen](https://github.com/sksizer/rust-ontogen) imports.

This package is released together with the `ontogen` crate and shares its version. Install the version that matches your `ontogen` dependency:

```bash
pnpm add @osdlc/ontogen-admin-types@0.10
```

It ships TypeScript source (`index.ts`) and has no runtime code.
